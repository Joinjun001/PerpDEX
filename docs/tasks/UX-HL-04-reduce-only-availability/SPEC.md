# UX-HL-04-A1 — Reduce Only 비활성 상태

## 목적
- 거래 터미널의 주문 폼에 Reduce Only 항목을 보여 주되, 실제 포지션·잔량·위험 정책이 확인되지 않았으므로 활성화하지 않는다.
- 기존 Market/Limit, Long/Short와 주문 미리보기·계정 미연결·MOCK 데이터 구조를 유지한다.

## 수락 조건
- 네이티브 체크박스와 label, 화면에 보이는 미지원 이유, 연결된 aria-describedby를 제공한다.
- 체크박스는 기본 및 정적 사이트에서 항상 disabled, unchecked다.
- 주문 미리보기 및 백엔드·지갑·서명/실주문 기능에 새 연결이나 계산을 추가하지 않는다.
- 포지션·잔량 정책 검증 및 M5~M8 승인 없이는 Reduce Only를 실제로 활성화하지 않는다.
- 실제 브라우저/스크린리더 시각 인수는 별도 진행한다.
