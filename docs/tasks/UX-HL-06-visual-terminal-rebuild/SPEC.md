# UX-HL-06 — 첨부 거래 화면 기반 터미널 구조 고도화

상태: **In Progress (2026-11-10, A1/A2 로컬 구현·검증; A3 브라우저 인수 보류, B1·C1·C2a·D1·D2·E1 로컬 구현/회귀 검증 완료, A3·C2b·F 브라우저 인수 보류)**

## 목표

`docs/architecture/HYPERLIQUID-TRADE-SCREEN-SPEC.md`의 A~I 영역을 바탕으로 현재 정적 PerpDEX 거래 터미널을 정보 밀도·상호작용·반응형 관점에서 고도화한다. Hyperliquid의 정보 구조를 참조하되 PerpDEX의 독립 디자인, 서명·정산·안전 아키텍처와 기능 상태를 보존한다.

## 구현 범위

- A: 상단/시장 헤더 + 3열/하단 계정 2차원 레이아웃
- B: 차트 도구/샘플 축/거래량을 지원 가능 범위에서 정직하게 시각화
- C: 단일 호가창의 Book/Trades 탭·스프레드·호가 깊이와 단위
- D: 주문 티켓의 밀도와 위험 정보(UNAVAILABLE·MOCK 경계 유지)
- E: 계정 하단 탭·데이터 테이블 공간 활용(기존 5개만 활성)
- F: 브라우저 인수와 회귀 검증

## 제외 범위·선행 게이트

- 실자산·운영 DB/RPC·Sepolia 배포·실계정 조회·주문 송신은 UX-HL-06의 작업 범위 밖이다.
- Cross/Unified/Pro·TP/SL·TWAP/Chase·Funding/청산가 계산은 서버 정책·M5~M9 승인/검증 없이 활성화하지 않는다.
- 미구현 차트 도구/캔들/거래량을 사용 가능한 실시간 기능으로 표기하지 않는다.
- 기존 UX-HL-01~04의 현재 테스트·데모 안전 동작을 삭제하거나 완료 상태를 재정의하지 않는다.
